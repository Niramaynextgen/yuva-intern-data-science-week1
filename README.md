# yuva-intern-data-science-week1
## Project Title
**Customer Churn and Repeat-Purchase Prediction in Beauty & Wellness**

## Overview
This project explores how data science can help beauty and skincare retailers identify customers who may become inactive and understand repeat-purchase behaviour. The goal is to develop a data-driven approach to customer retention and more effective marketing strategies.

## Objectives
- Define a business problem relevant to the beauty and wellness industry.
- Identify research questions and testable hypotheses.
- Determine the key variables and data required for analysis.
- Propose an analytical approach using exploratory data analysis and machine learning.

## Proposed Methodology
The project will explore customer transaction history using:
- Recency, Frequency, and Monetary (RFM) analysis
- Customer segmentation
- Exploratory Data Analysis (EDA)
- Logistic regression and tree-based predictive models

## Expected Outcome
The project aims to establish a foundation for predicting customer inactivity, understanding purchasing patterns, and supporting targeted customer-retention campaigns.
